On ne travaille que sur les mots (ou pour être exact les racines des mots) en analysant uniquement leur fréquence dans le texte.

Méthodologie statistique

L’étude comprend deux partie :

  • un questionnaire simple dont toutes les réponses sont qualitatives ou ont pu être discrétisées.
  • Des entretiens dirigés en texte brut.

Questionnaires

Vu le très faible nombre de cas aucun test ne eut être réalisé, l’analyse sera uniquement descriptive. Plusieurs tableaux présentant les réponses seront réalisés (nombre & pourcentage) :

  • Profil du répondant
  • Initiation d’une thérapie orale
  • Analyse médicamenteuse et conciliation
  • Évaluation globale du patient
  • Recours aux soins de support
  • Suivi des patients sous thérapies orales
  • Organisation future

Entretiens

L’analyse des entretiens a été réalisée en text mining. L’analyse a été uniquement descriptive & concentrée sur les mots les plus fréquents et les associations de mots.

Une première étape a été la transformation du texte en extrayant les mots qui sont réduits à leur racine (suppression des conjugaisons, des accords etc. - package tidytext1). Ensuite les mots considérés comme vides (pronoms, auxiliaires, verbe courants…) ont été supprimés pour ne garder que les mots considérés comme intéressants (package proustr2. Pour chaque répondant les mots les plus utilisés ont été présentés en tableau puis sur deux graphiques : graphique en barre & nuage de mots (package ggwordcloud3. Une comparaison des réponses entre les participants a été présentée. Enfin les associations de pot avev les mots les plus fréquents a été réalisée par une analyse en corrélation. Le seuil retenue pour suggérer une corrélation a été un R supérieur à 0,6.

L’analyse statistique a été réalisée avec le logiciel R4 & divers packages. Outre ceux cités dans le texte on a utilisé en particulier tidyverse5 & baseph6.

Mots les plus fréquents

Le mot qui revient le plus souvent est “patient”. On peut donc s’intéresser aux mots qui sont associés à ce mot. On va donc créer un tableau de contingence entre le mot “patient” et les autres mots significatifs. On prend comme limite un coefficient de corrélation supérieur à 0,6. s

Code 
docs <- Corpus(VectorSource(tt$texte))
docs <- tm_map(docs, content_transformer(tolower))
docs <- tm_map(docs, removeNumbers)
docs <- tm_map(docs, removeWords, stopwords("french"))
docs <- tm_map(docs, removeWords, mesmots$value) 
docs <- tm_map(docs, removeWords, "ver") 
docs <- tm_map(docs, removePunctuation)
docs <- tm_map(docs, stripWhitespace)
docs <- tm_map(docs, stemDocument)
dtm <- TermDocumentMatrix(docs)
aap <- findAssocs(dtm, terms = "patient", corlimit = 0.59)

aa <- as_tibble(aap$patient, rownames = "mots") |>
  dplyr::filter(! mots == "ver") |> 
  dplyr::rename(corr = value) |>
  dplyr::arrange(desc(corr)) |> 
  ggplot() +
  aes( x =  fct_reorder(mots, corr, .desc = TRUE), y = corr, fill = corr) +
    geom_col() +
  scale_fill_viridis_c() +
    theme_light() +
    labs(
    title = "Mots associés au mot \"patient\"",
    caption = "Mots associés au mot \"patient\" (cœfficient de corrélation
    supérieur à 0.6)", 
    y = "Coefficient de corrélation"
  ) +
  theme(
    plot.title = element_text(size = 14, face = "bold"),
    plot.subtitle = element_text(size = 12),
    axis.title.y.right = element_blank(),
    legend.title = element_text(size = 12),
    axis.title.y = element_text(size = 12),
    axis.title.x = element_blank(),
    axis.text.x = element_text(size = 10, angle = 50, hjust = 1),
